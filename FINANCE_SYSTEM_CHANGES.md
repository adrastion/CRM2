### 3. Варианты оплаты тренера

#### Вариант 1: Процент от суммы оплаты
- `salaryType = 'percentage'`
- `salaryAmount` - процент (например, 30 = 30%)
- Расчет: `(общая_сумма_оплаты * процент) / 100`

#### Вариант 2: Оплата за каждого ученика
- `salaryType = 'per_student'`
- `salaryAmount` - цена за каждого ученика
- Расчет: `количество_посещений * цена_за_каждого`

#### Вариант 3: Фиксированная плата
- `salaryType = 'fixed'`
- `salaryAmount` - фиксированная сумма за тренировку
- Распределяется между всеми присутствующими

#### Вариант 4: Оплата за тренировку
- `salaryType = 'per_training'`
- `salaryAmount` - фиксированная сумма за тренировку
- Распределяется между всеми присутствующими

#### Вариант 5: Индивидуальное занятие
- `salaryType = 'individual'`
- `salaryAmount` - общая стоимость занятия
- `salaryPercentage` - процент, который получает тренер (остальное - зал)
- Расчет: `(стоимость_занятия * процент_тренера) / 100`

## Важные замечания

1. **Приоритет абонементов**: Если у клиента есть активный абонемент (месячный или на посещения), деньги НЕ списываются с баланса. Абонемент имеет приоритет.

2. **Недостаточный баланс**: Если у клиента недостаточно средств на балансе, посещение все равно создается, но деньги не списываются. Это можно расширить, добавив систему задолженностей.

3. **Транзакции**: Все финансовые операции записываются в таблицу `transactions` для полной прозрачности и возможности аудита.

4. **Индивидуальные занятия**: Для варианта 5 (individual) важно, чтобы в группе был только один клиент. В противном случае расчет не производится.
