# Переход на реальные платежи YooKassa

## Что нужно изменить

### 1. Обновить переменные окружения

В файле `.env` на сервере замените тестовые данные на реальные:

```bash
# Замените на реальные данные из личного кабинета YooKassa
YOOKASSA_SHOP_ID="ваш-реальный-shop-id"
YOOKASSA_SECRET_KEY="ваш-реальный-secret-key"

# Удалите или установите в false (переменная не используется в коде, но для ясности)
YOOKASSA_TEST_MODE="false"
```

**Где взять реальные данные:**
1. Войдите в [личный кабинет YooKassa](https://yookassa.ru/my)
2. Перейдите в раздел "Настройки" → "API"
3. Скопируйте:
   - **Shop ID** (идентификатор магазина)
   - **Secret Key** (секретный ключ)

⚠️ **ВАЖНО:** Используйте реальные данные только на продакшн-сервере!

### 2. Настроить Webhook URL в личном кабинете YooKassa

1. Войдите в [личный кабинет YooKassa](https://yookassa.ru/my)
2. Перейдите в раздел "Настройки" → "HTTP-уведомления"
3. Укажите URL для webhook'ов:
   ```
   https://ваш-домен.ru/api/subscription/webhook
   ```
   Например: `https://profsportcrm.ru/api/subscription/webhook`

4. Выберите события для отправки:
   - ✅ `payment.succeeded` (обязательно)
   - ✅ `payment.canceled` (рекомендуется)
   - ✅ `payment.waiting_for_capture` (опционально)

### 3. Проверить IP-адреса YooKassa (опционально, для дополнительной безопасности)

Для дополнительной защиты webhook'ов можно добавить проверку IP-адресов в middleware.

**IP-адреса YooKassa для реального режима:**
- `185.71.76.0/27`
- `185.71.77.0/27`
- `77.75.153.0/25`
- `77.75.156.11`
- `77.75.156.35`
- `77.75.154.128/25`

### 4. Обновить env.example (для документации)

Обновите файл `env.example` с примером реальных данных (без реальных ключей):

```bash
# YooKassa Payment Gateway (Production)
YOOKASSA_SHOP_ID="your-production-shop-id"
YOOKASSA_SECRET_KEY="your-production-secret-key"
YOOKASSA_TEST_MODE="false"
```

## Что НЕ нужно менять в коде

✅ **URL API уже правильный:** `https://api.yookassa.ru/v3` - это реальный URL, не тестовый

✅ **Логика обработки платежей** уже готова для реального режима

✅ **Webhook обработка** работает одинаково для тестового и реального режима

## Проверка после перехода

1. **Создайте тестовый платеж:**
   - Перейдите на страницу тарифов
   - Выберите тариф и создайте платеж
   - Проверьте, что платеж создается с реальными данными

2. **Проверьте webhook:**
   - После успешной оплаты проверьте логи сервера
   - Должны появиться сообщения о получении webhook'а
   - Подписка должна автоматически активироваться

3. **Проверьте логи:**
   ```bash
   pm2 logs martial-arts-crm
   ```
   Ищите сообщения:
   - `Processing YooKassa webhook for payment:`
   - `Payment status from YooKassa API:`
   - `Subscription activated successfully:`

## Важные замечания

⚠️ **Безопасность:**
- Никогда не коммитьте реальные ключи в Git
- Храните `.env` файл в безопасности
- Используйте разные ключи для тестового и реального режима

⚠️ **Тестирование:**
- Рекомендуется сначала протестировать на небольшой сумме
- Убедитесь, что webhook'и приходят корректно
- Проверьте, что подписки активируются автоматически

⚠️ **Мониторинг:**
- Следите за логами после перехода
- Проверяйте статусы платежей в личном кабинете YooKassa
- Убедитесь, что все платежи обрабатываются корректно

## Откат на тестовый режим (если нужно)

Если нужно вернуться к тестовому режиму:

1. Замените переменные окружения на тестовые
2. Обновите webhook URL в личном кабинете YooKassa (если нужно)
3. Перезапустите сервер:
   ```bash
   pm2 restart martial-arts-crm
   ```

## Поддержка

Если возникли проблемы:
1. Проверьте логи сервера
2. Проверьте настройки в личном кабинете YooKassa
3. Убедитесь, что webhook URL доступен извне
4. Проверьте, что переменные окружения установлены правильно
